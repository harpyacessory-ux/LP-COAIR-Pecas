# Briefing do cliente

Coloque aqui o documento recebido do cliente (.docx, .pdf, .md ou .txt), sem editar. O agente lê este diretório antes da entrevista (PROMPT-PADRAO-LP, seção 0) e registra o mapa de aproveitamento em `docs/BRIEFING.md`.

O padrão prevalece: estrutura, ordem e CTAs sugeridos aqui não são seguidos; o conteúdo é reaproveitado.

**Esta pasta fica fora do git** (só este README é versionado). É material bruto do cliente — proposta, catálogo, prints, mensagens — e não pode depender de o repositório da LP ser privado. Tudo o que a LP precisa dele vai, organizado, para `docs/BRIEFING.md`, que é versionado. Guarde o original também onde a agência guarda os arquivos do cliente.
